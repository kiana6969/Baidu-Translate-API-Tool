# Baidu-Translate-API-Tool
基于 Python 实现的**百度翻译 API 调用工具**，个人首个实战项目，面向对象工程化开发。

## 项目亮点
-   **安全设计**：规避密钥硬编码，运行时输入 AppID/密钥，可直接开源上传
-   **完整功能**：中英互译、循环交互菜单、翻译历史持久化存储
-   **健壮性强**：MD5 签名加密、网络超时处理、JSON 异常捕获、输入合法性校验
-   **工程规范**：类结构封装、注释清晰、模块化、可直接部署运行

## 技术栈
Python 3.12 + requests + hashlib + json + time

## 使用方法
1. 安装依赖：`pip install requests`
2. 运行 `main.py`，输入百度翻译开放平台 AppID 与密钥
3. 选择功能：1翻译 / 2查看历史 / 3退出
4. 翻译记录自动保存至 `history.txt`

## 项目总结
本项目完整体现**需求拆解、接口调用、异常处理、用户体验优化**的开发思维，适配后端/数据处理方向岗位实践。
